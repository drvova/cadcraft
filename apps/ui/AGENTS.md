# CADCraft web — agent notes

## UI work

Before you add or change a component, a screen, a style, a token, or copy in the UI:

1. Read `docs/generated/llms.txt`, then `docs/generated/rules.md`, `docs/system/decisions.md` and the twin in `docs/generated/` of each component you touch.
2. Use a registry component (`docs/registry.json`) and the tokens in `src/tokens.css`. If none fits, open a gate before writing one.
3. Colours, type, spacing, radius, motion and icons come from `src/tokens.css` and the components in `src/ui` — never a raw value, never a second copy of a component.

Before you finish: run `bun run check`, and capture the changed screens at 390 and 1280.

`cargo xtask ci` (and so CI) runs the blocking check through `cargo xtask ui`. Before a change lands, `node scripts/check-system.mjs --explain <rule-id>` gives a rule's fix, and `node scripts/check-system.mjs --changed <base> --warn` warns only on the lines the change added. Fix each warning, or say in the PR why it stays.

Components (import, job):
- Button `../../../../src/ui/Button`: It runs one action the moment its label says so: it never navigates and never holds a value.
- Chip `../../../../src/ui/Chip`: It shows one compact fact, a keyword or a suggestion, and it only acts when the caller gives it a handler.
- Field `../../../../src/ui/Field`: It takes one line of text and hands every keystroke back to the caller, who owns the value.
- IconButton `../../../../src/ui/IconButton`: It runs one action drawn as a single glyph, and its title is both its accessible name and the hint a sighted person reads.
- Kbd `../../../../src/ui/Kbd`: It shows the key or shortcut that runs the action beside it, as a fact to read and never as a control.
- Row `../../../../src/ui/Row`: It is the full-width clickable band of a list: a menu item, a property row or a layer, marked current when it is the selected one.
- SectionLabel `../../../../src/ui/SectionLabel`: It names a panel's section as a real heading, so a screen reader can jump between the sections by heading.
- Tab `../../../../src/ui/Tab`: It brings one view of a strip to the front: a layout over the drawing or a chat in the assistant, marked selected when it is the one show...
